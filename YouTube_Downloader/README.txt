YouTube 고화질 다운로드

실행: release 폴더의 YouTubeDownloader.exe 더블클릭
이 PC 개발용 실행: 실행.cmd

1. YouTube 영상 공유 링크 입력 후 영상 확인
2. 최고 화질 자동 또는 제공되는 해상도 상한 선택
3. 저장 폴더 확인 후 다운로드 시작
4. 영상/음성 다운로드 및 병합이 모두 끝나면 완료 표시

최고 화질은 원본이 제공하는 범위입니다. 업스케일하지 않습니다.
MP4 우선이며 코덱 조합에 따라 MKV로 저장될 수 있습니다.
진행률은 각 트랙별이며 음성 다운로드에서 다시 시작할 수 있습니다.
동일 영상 완료 파일이 있으면 덮어쓰지 않습니다. 다른 화질은 별도 폴더에 저장하세요.
취소 시 미완료 파일은 보관되며 같은 설정으로 다시 받으면 이어받을 수 있습니다.
진행 중인 라이브 방송 및 재생목록 다운로드는 지원하지 않습니다.
YouTube 정책 변경, 로그인 요구, 지역 제한 등으로 다운로드가 실패할 수 있습니다.
본인 콘텐츠 또는 다운로드 권한이 있는 영상에 사용하세요.

직원 PC에 전달할 때는 release 폴더 전체를 복사하세요.
tools 폴더를 함께 보관해야 합니다. 별도 Python 설치는 필요 없습니다.
